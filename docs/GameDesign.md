# 게임 기획서

> 상태 표기: **확정** = 사용자가 결정함 / **제안** = 설계 측 제안, 사용자 확인 전 / **미정** = 결정 필요(구현 전 사용자에게 질문)
> 최종 갱신: 2026-10-12

## 1. 콘셉트 — 확정

- 유저가 카드를 직접 제작한다: 이미지, 등장(소환)·퇴장(사망) 사운드, 공격력·체력·코스트, 효과.
- 제작한 카드로 덱을 짜서 다른 유저와 **1대1 온라인 대전**을 한다.
- 규칙 뼈대는 **하스스톤**. 단, 기물 외에 원신 "칠성소환"처럼 **필드·동료·소환물**이 별도 영역에 깔린다.
- 플랫폼: **Windows, Mac**. 이후 **모바일 추가 가능성** 있음. **크로스플랫폼 대전 필수.**
- Steam 출시 계획은 있으나 미확정.

## 2. 용어 — 확정

| 용어 | 의미 |
|---|---|
| **공격력** | 말 그대로 공격력 |
| **체력** | 말 그대로 체력 |
| **점수** | 카드의 가치. 효과, 공격력, 체력 등에 의해 변동 (아래 §6) |
| **코스트** | 카드를 낼 때 쓰는 자원. 하스스톤의 마나에 해당 |
| **효과** | 카드의 효과 (아래 §7) |
| **기물** | 기물 영역에 놓이는, 공격력·체력을 가진 카드. 하스스톤의 "하수인"에 해당 (2026-10-12부터 이 용어로 통일). 코드 이름은 `Minion` |

> 주의: 과거 대화에서 "코스트"를 카드 가치 의미로 쓴 적이 있으나, **현재는 위 정의가 기준**이다.

## 3. 대전 개요

### 3.1 기본 — 확정
- 1대1, 하스스톤처럼 턴을 번갈아 진행한다.

### 3.3 게임 모드 — 확정 (2026-10-12)

| 모드 | 내용 | 시기 |
|---|---|---|
| **싱글 배틀** | 컴퓨터와 1대1. 난이도 쉬움·보통·어려움·챌린지 | 먼저 (M3) |
| **테스트 배틀** | 개발자용. 싱글 배틀과 **분리**해 구현 (§3.5) | 나중 (M3.5) |
| 온라인 대전 | §8 | M6 |

- 한 컴퓨터에서 2인이 번갈아 하는 로컬 대전(핫시트)은 만들지 않는다. 그 자리를 싱글 배틀이 대신한다.

### 3.4 싱글 배틀 난이도 — 확정 (2026-10-12)
- 난이도는 **실력(판단력) 차이만** 낸다. 체력·코스트 보너스 같은 유리한 조건은 없다.
- 컴퓨터는 플레이어의 손패·덱을 보지 않는다. 단 **챌린지는 플레이어 손패를 본다** (덱 순서는 못 본다).
- 컴퓨터가 카드를 내면 포켓몬 카드 게임 포켓·마스터 듀얼처럼 카드를 화면에 크게 띄운다. 행동 사이 간격은 개발 측이 정한다.
- 구현 (2026-10-12):
  - 쉬움: 계산 없이 낼 수 있는 카드·공격을 무작위로 고름.
  - 보통: 행동마다 결과를 계산해 판세 점수가 가장 좋은 것.
  - 어려움: 상위 후보마다 내 턴 끝까지 + 상대의 다음 턴 대응까지 시뮬레이션해서 고름.
  - 챌린지: 어려움 + 더 많은 후보·가정 + 플레이어 손패 공개.
  - 공정성: 컴퓨터는 계산할 때 숨긴 정보(상대 손패·덱 순서·난수 결과)를 모르는 상태로 가정해 본다.
  - 샘플 덱 40판 측정 승률: 보통 vs 쉬움 98%, 어려움 vs 보통 60%, 챌린지 vs 보통 70%, 챌린지 vs 어려움 53%. 어려움↔챌린지 차이는 테스트 배틀(§3.5 AI 자동 대전)로 조정 예정.
  - 재측정 (2026-10-15, 기물 5칸·피해 트리거, 샘플 덱 40판·자리/덱 번갈아): 보통 vs 쉬움 95%, 어려움 vs 보통 60%, 챌린지 vs 보통 60%, 챌린지 vs 어려움 50%.

### 3.5 테스트 배틀 (개발자용) — 확정 (2026-10-12), 구현은 나중
1. 시작 상태 직접 설정 (양쪽 손패·덱 순서·보드·영웅 체력·코스트·시드)
2. 양쪽 다 직접 조종 (1인 2역)
3. 실행 중 수정 (카드 추가, 체력·코스트 변경 등 치트 패널)
4. 한 수씩 진행 / 되돌리기
5. AI 판단 이유 표시 (후보 행동과 점수)
6. AI끼리 자동 대전 N판 (승률·버그 확인, 밸런스용)
7. 상황 저장·불러오기 (반복 테스트)

## 4. 영역(Zone)

### 4.1 플레이어별 영역 — 확정(칸 수), 제안(나머지)

| 영역 | 칸 수 | 비고 |
|---|---|---|
| 기물 | **5** | 확정 (2026-10-15에 3 → 5로 변경) |
| 필드 | **1** | 확정 |
| 동료 | **4** | 확정 |
| 소환물 | **4** | 확정 |
| 덱 / 손패 / 묘지 | — | 제안 |
| 영웅 | 1 | 제안 (하스스톤식 영웅 체력) |

- 각 플레이어가 **자기 영역을 따로** 가진다 (필드 칸도 플레이어마다 1개). — 확정

### 4.2 필드 교체 — 확정
- 내가 새 필드를 내면 **내 기존 필드와 교체**된다.
- 교체된 기존 필드는 퇴장하며 **"파괴 시" 효과가 발동**한다.
- 필드 효과가 누구에게 적용되는지는 카드의 **효과 대상 설정**으로 정한다 (내 쪽만 / 상대 쪽만 / 양쪽).

### 4.3 영역이 가득 찼을 때 — 확정 (2026-10-12)
- **필드를 제외한 영역(기물·동료·소환물)은 가득 차면 더 놓을 수 없다.**
  - 손패에서 내는 경우: 해당 영역이 가득 차면 그 카드를 낼 수 없다.
  - 효과로 놓이는 경우(소환물 생성 등): 아무 일도 일어나지 않고 무시된다.
- 필드는 §4.2 교체 규칙을 따른다.
- **같은 소환물이 또 생성될 때의 처리는 소환물마다 카드 옵션으로 고른다.** — 확정 (2026-10-12)
  - `새로 놓기`: 하나 더 놓는다 (칸이 가득 차면 무시).
  - `사용 횟수 갱신`: 새로 놓지 않고 기존 소환물의 사용 횟수를 처음 값으로 다시 채운다 (원신 방식). 새 칸이 필요 없으므로 영역이 가득 차 있어도 동작한다. — 제안
  - "같은 소환물" = 같은 카드의 같은 효과가 만든 소환물. — 제안

## 5. 카드 종류

| 종류 | 설명 | 상태 |
|---|---|---|
| 기물 | 기물 영역에 놓임. 공격력·체력 보유, 공격/피격 가능 | 확정 |
| 필드 | 필드 영역(1칸). 지속 효과, 교체 규칙(§4.2) | 확정 |
| 동료 | 동료 영역. 원신의 동료(지원) 카드처럼 지속·조건부 효과. **사용 횟수는 카드마다 선택** (n회 쓰면 퇴장 / 영구 지속) | 확정 |
| 소환물 | 소환물 영역. 원신처럼 **사용 횟수**를 가지고 **턴 종료 시 자동 발동**, 횟수 0이면 제거 | 확정 |
| 주문 | 즉시 효과를 내고 묘지로 감 | 확정 |

### 5.1 세부 규칙 — 확정 (2026-10-12)
- **소환물은 다른 카드의 효과로만 생성**된다 (손패·덱에 들어가지 않음).
  - 소환물 정의는 그것을 생성하는 카드 안에 포함된다.
  - 소환물의 점수는 그것을 생성하는 카드의 점수에 합산된다.
- **필드·동료·소환물은 공격 대상이 될 수 없고 체력이 없다.** 효과(파괴, 사용 횟수 감소 등)로만 제거된다. 전투(공격)는 기물과 영웅끼리만 한다.
- 공격력·체력은 기물 전용 속성, 사용 횟수는 소환물(필수)·동료(선택) 속성이다.

### 5.2 규칙 엔진 구현 시 정한 세부 규칙 — 제안 (2026-10-12, 사용자 확인 필요)

M2 구현에 필요해 하스스톤 기준으로 임시로 정했다. 값이 있는 것은 `RuleConfig`에 있고, 바꾸려면 말해 주면 된다.

| 항목 | 현재 동작 |
|---|---|
| 낸 턴에 공격 | 불가 (`CanAttackOnPlayedTurn = false`). 돌진 키워드는 없음 |
| 공격 횟수 | 기물당 턴마다 1회 (`AttacksPerTurn`) |
| 영웅 공격 | 없음. 영웅은 반격하지 않음 (Q11과 함께 결정) |
| 사용 횟수 소모 | 효과가 1번 처리될 때마다 1 소모 (턴 시작/종료·피격·공격·카드 사용 시 효과). 등장·퇴장·상시 효과는 소모하지 않음 |
| 소환물 퇴장 | 묘지로 가지 않고 완전히 사라짐. 동료·필드·기물은 묘지로 |
| 손패 초과 드로우 | 소멸 영역으로 감 |
| "체력 n 이하" 조건 | 효과를 가진 카드의 체력, 체력이 없는 카드면 주인 영웅의 체력 |
| "특정 종류 카드 존재" 조건 | 내 보드(기물·필드·동료·소환물)에 해당 종류가 n개(최소 1) 이상 |
| 드로우·버리기 대상 | 대상의 주인 플레이어 (영웅이면 그 플레이어). 버리기는 무작위 |
| 코스트 증감 대상 | 영웅을 대상으로 하면 그 플레이어의 손패 전체 |
| 선택 대상 | 등장 시 효과에만 사용 가능. 카드를 낼 때 반드시 골라야 함 |
| 상시(지속) 효과 | 공격력·체력·코스트 증감만 가능. 무작위·선택 대상 불가 |
| 피해·회복 대상 | 영웅과 기물만. 필드·동료·소환물은 체력이 없어 무시 |
| 체력 감소로 0 이하 | 그 즉시 사망 (§7.2). 상시 체력 보정이 사라져 0 이하가 되는 경우 포함 |
| 무한 연쇄 | 명령 1개당 체인 처리 1000회를 넘으면 남은 체인·대기 효과를 버림 |
| 선공 결정 | 시드 기반 무작위 |
| 후공 보정 카드 | 규칙 플래그만 있음. 어떤 카드인지는 미정 (지금은 지정하지 않으면 안 줌) |

## 6. 점수 시스템 — 확정

- **점수 = 카드의 가치.** 카드를 만들 때 자동 계산된다.
  - 좋은 효과 추가, 공격력·체력 증가 → **점수 증가**
  - 나쁜 효과(패널티) 추가, 코스트 증가 → **점수 감소**
- **대전 제한은 방 규칙으로** 한다: 예) "점수 N 이하 카드만 사용 가능".
  - 장점: 밸런스 패치로 점수가 바뀌어도 카드가 "불법"이 되지 않고, 해당 방에서 못 쓸 뿐이다.
- 점수 계산은 **정적 클래스 하나**(`ScoreCalculator`)로 구현하고, 카드 에디터 미리보기와 대전 시작 시 덱 검증이 같은 코드를 쓴다. — 확정
- 점수 가중치 테이블은 버전을 가진 데이터로 관리한다(대전 시 양쪽 버전 일치 확인). — 제안
- 패널티로 내릴 수 있는 점수에 **하드캡**을 둔다. — 확정
- 방 규칙 형태 — 확정 (2026-10-13): **카드별 점수 상한만** 둔다("점수 N 이하 카드만", 끄면 제한 없음). 덱 총합 상한은 두지 않고 덱 점수 합계는 참고로만 보여 준다. 점수는 `ScoreCalculator.Calculate` 실제 값 기준.
- 덱 빌더의 "점수 기준 필터" = 카드 목록을 점수 범위로 거르고 정렬하는 **화면 기능**일 뿐, 덱에 점수 제한을 걸지 않는다. 덱 점수 합계는 참고 정보로만 보여 준다. — 확정 (2026-10-13)

### 6.1 점수 공식 v1 — 확정 (2026-10-13, 숫자는 `ScoreTable` 데이터라 조정 가능)

**기준: 점수 0 = 코스트에 맞는 카드** (하스스톤 "코스트 N → 공격력+체력 2N+1" 기준). 0보다 크면 코스트 대비 강함.

| 항목 | 점수 |
|---|---|
| 기본 | −10 (공격력+체력 = 2×코스트+1인 카드가 0점이 되는 값. 포함된 소환물은 기본·코스트 없음) |
| 공격력·체력 1 | +10 |
| 코스트 1 | −20 |
| 키워드 | 도발 +10, 은신 +15, 선봉 +30, 보물상자 +30, 일회성 −5 |

**효과 1개 = 행동 기본점 × 수치 × 대상 배율 × 트리거 배율 × 조건 배율 (× 선택 발동 배율)**

- 행동 기본점(수치 1당): 피해 10, 회복 5, 드로우 30, 버리기 20, 공격력·체력 증감 10, 파괴 60(수치 무관), 코스트 증감 15, 사용 횟수 증감 10, 소환물 생성 = 포함된 소환물 점수.
- 방향: 행동이 대상 주인에게 좋은지(회복·드로우·증가) 나쁜지(피해·버리기·파괴·코스트 증가)와 대상 쪽(아군/적)으로 부호를 정한다. 상대에게 나쁘거나 나에게 좋으면 +, 반대면 패널티(−). 선택 대상은 유리하게 고른다고 보고 항상 +.
- 대상 배율: 자신·영웅 ×1, 무작위 적 기물 n ×n, 선택 대상 ×1.3, 모든 적 기물·모든 아군 기물 ×2.5.
- 트리거 배율: 등장 ×1, 퇴장 ×0.8, 피해 받을/줄 때 6종(옛 피격)·공격 ×1.2, 카드 사용·상시 ×1.5, 턴 시작·종료 ×2. 사용 횟수가 있는 카드의 반복 트리거(턴 시작·종료·피해 받을/줄 때·공격·카드 사용)는 사용 횟수 × 1 (최대 ×3). (2026-10-15: 점수표 Version 2)
- 조건 1개당 ×0.7. 선택 발동 ×1.1, 단 **선택 발동 패널티는 0점** (안 쓰면 그만이므로).
- **하드캡: 패널티(음수 효과·음수 키워드)로 깎이는 점수는 합계 최대 30.** 코스트는 패널티가 아니다.
- **음수 점수:** 계산값은 음수가 될 수 있다. 카드 표시는 최소 0, 카드 편집 화면에서는 실제 값(음수 포함)을 보여 준다. — 확정
- 정수 연산: 배율은 백분율 정수로 곱하고 단계마다 /100 (결정론).

### 참고: 설계 시 고려할 악용 패턴 (제안)
1. 패널티가 시너지로 오히려 이득이 되는 경우 (버리기 덱의 "손패 버리기" 등) → 하드캡
2. 스탯·키워드 조합의 비선형 가치 (독 + 광역 등) → 구간 테이블, 조합 가산
3. 같은 효과도 발동 빈도에 따라 가치가 다름 (소환 시 1회 vs 매 턴) → 트리거 배율

## 7. 효과 시스템 — 확정 (초기 목록, 2026-10-12)

효과 1개 = **트리거 + 조건(0개 이상) + 대상 + 행동**. 블록을 조합해 만든다. 각 블록은 실행 로직과 점수 데이터를 함께 등록한다(레지스트리 방식).

| 블록 | 초기 목록 |
|---|---|
| 트리거 | 소환(등장) 시, 사망/파괴 시, 내 턴 시작/종료, 피해를 받을 때(효과/전투/모든), 피해를 줄 때(효과/전투/모든), 공격 시, 카드 사용 시, 상시(지속) — 피해 트리거는 §7.6 (2026-10-15 변경, 기존 "피격 시" 대체) |
| 조건 | 체력 n 이하, 내 기물 n개 이상, 손패 n장 이하, 특정 종류 카드 존재 |
| 대상 | 자신, 내 영웅, 상대 영웅, 무작위 적 기물 n, 모든 적 기물, 모든 아군 기물, 선택 대상 |
| 행동 | 피해, 회복, 드로우, 버리기, 공격력/체력 증감, 소환물 생성, 사용 횟수 증감, 코스트 증감 |
| 키워드 | 도발, 은신, 선봉, 일회성, 보물상자 (아래 §7.1) |

- 블록과 키워드는 **나중에 추가될 수 있다.** 새 블록은 레지스트리에 등록만 하면 기존 카드·코드에 영향이 없게 만든다. — 확정

### 7.1 키워드 — 확정 (2026-10-12)

| 키워드 | 대상 카드 | 규칙 |
|---|---|---|
| 도발 | 기물 | 상대는 도발 기물부터 공격해야 한다. 도발이 둘 이상이면 그중에서 고른다. |
| 은신 | 기물 | 기물의 **공격 대상으로만** 지정할 수 없다. 효과의 대상(선택·무작위·전체)은 될 수 있다. 공격해도 **풀리지 않는다**. |
| 선봉 | 기물 | 이 기물이 등장하면 주인이 1장 드로우. |
| 일회성 | 주문 | 사용하면 묘지로 가지 않고 이번 대전에서 완전히 제거된다(소멸). 슬레이 더 스파이어의 "소멸"과 같음. |
| 보물상자 | 기물 | 이 기물이 쓰러지면(사망·파괴) 주인이 1장 드로우. |

- 은신 기물이 도발도 가진 경우, 공격할 수 없으므로 도발 강제에서도 빠진다. — 제안

### 7.2 체인 (효과 처리 순서) — 확정 (2026-10-12)

**유희왕의 체인**을 기준으로 한다.

1. 행동(카드 내기·공격·턴 종료 등)은 즉시 일어나고, 그 연출(소환 연출 등)이 바로 재생된다.
2. 그 행동으로 발동 조건을 만족한 효과들은 **대기 효과**가 된다. 체인은 **현재 턴 플레이어부터** 체인 기회를 받아 시작한다.
   - 효과는 카드에서 **강제**(조건이 되면 반드시 발동) / **선택**(발동할지 플레이어가 고름)을 정한다. 선봉·보물상자 같은 키워드 효과는 강제.
3. **체인에는 한 번에 하나의 효과만 올린다.** (2026-10-12 확정) 체인 기회를 받은 플레이어는 자기 대기 효과(나중에는 대응 효과도) 중 **하나를 올리거나 패스**한다.
   - **처음 발동한 효과(체인 1)** 다음: **발동자 → 상대** 순으로 체인 기회.
   - **체인으로 건 효과(체인 2 이후)** 다음: **상대 → 건 사람** 순으로 체인 기회.
   - 둘이 연속으로 패스하면 체인이 닫힌다.
   - 아직 올리지 않은 **강제 효과가 남아 있으면 패스할 수 없다** (하나를 올려야 함). 남은 것이 강제 효과 1개뿐이면 자동으로 올린다. — 제안
   - 체인이 닫힐 때 남은 **선택 효과는 발동하지 않는다**. — 제안
   - 올릴 수 있는 효과가 없으면 묻지 않고 **자동 패스**.
   - 대응용 블록(예: "상대가 카드를 냈을 때", "효과가 발동했을 때", 행동 "무효화")은 **구조만 만들고 블록은 나중에** 추가한다.
   - 체인에 효과가 하나 올라갈 때마다 **발동 연출**이 재생된다.
   - 체인 기회 창: 올릴 수 있는 효과를 **한 창에 모두** 보여 주고, **무조건 사용(강제)** 효과와 **체인 걸 수 있는(선택)** 효과를 **색이 다른 얇은 선 상자**로 나눠 묶는다 (강제 = 주황, 선택 = 하늘색). 효과가 많아 일정 높이(약 5줄)를 넘으면 **스크롤**한다. — 확정 (2026-10-12)
4. 체인이 닫히면 **마지막에 올라간 효과부터** 처리한다. 효과 하나의 **처리 연출**이 끝난 뒤 다음 효과를 처리한다. 무효화된 효과는 "발동 실패" 연출만 재생된다.
5. 피해로 체력이 0 이하가 되면 **그 즉시 사망**한다.
6. 체인 처리 도중 새로 발동한 효과(예: 사망한 보물상자)는 **지금 체인이 끝난 뒤 새 체인**을 만든다 (2번 규칙대로).

예시 (사용자 설명):
1. 카드 소환 → 즉시 소환 연출
2. 체인 1 (나): 방금 소환한 카드의 선봉 효과 A → 발동 연출(약한 반짝임)
3. 체인 2 (상대): 카드 소환에 대응한 효과 B(무효화) → 발동 연출
4. 체인 3 (나): 효과 B에 대응한 효과 C(무효화) → 발동 연출
5. 상대 패스 → 체인 닫힘
6. 효과 C 처리 + 처리 연출(대상 카드를 사슬로 묶기)
7. 효과 B 처리 → C에 무효화됨 → 발동 실패 연출
8. 효과 A 처리 + 처리 연출(깃발이 흩날림)

### 7.3 연출 — 확정 (2026-10-12)
- 연출은 두 층이다.
  - **시스템 연출**: 소환(등장), 사망·파괴, 드로우, 피해·회복 숫자 등 **게임에서 일어난 일**의 연출. 항상 재생된다. 소환·사망 연출은 끌 수 없고 **어떤 연출을 쓸지만** 카드에서 바꿀 수 있다.
  - **효과 연출**: 카드 효과마다의 **발동 연출**(체인에 올라갈 때)과 **처리 연출**(처리될 때). 카드에서 바꾸거나 **끌 수 있다**. 예: 보물상자 연출을 꺼도 드로우 연출은 재생된다.
- 광역 효과의 피격 연출은 효과마다 **하나씩 차례로 / 한 번에**를 카드에서 고른다. 대상별 연출(피격 → 사망 등)은 병렬로 진행된다.
- 미정: "보물상자 연출이 사망 연출을 대신하게 하는" 설정을 둘지 (처음 설명과 뒤 설명이 갈림).
- 기본 연출(제안, 사용자 커스터마이징 전제): 카드 내기 = 손에서 칸으로 날아가 내려앉음 + 등장 사운드 / 공격 = 대상에게 돌진 후 복귀 / 피해·회복 = 숫자 + 흔들림 / 사망·파괴 = 기울며 사라짐 + 퇴장 사운드 / 주문 = 화면 가운데 크게 표시 후 효과 / 소환물 발동 = 빛남 후 효과.
- 연출 중 조작: 손패 카드를 집어(포인터를 따라옴) 움직일 수는 있지만 **내거나 대상을 고를 수는 없다** (슬레이 더 스파이어 방식).
- 연출 방식이 추가되어도 기존 코드에 영향 없도록 확장형 구조. — 확정

### 7.4 연출 공유 — 예정(나중), 세부 미정 (2026-10-12)
- 사용자 요청: 유저가 만든 연출을 **다른 유저와 공유**할 수 있으면 좋겠다. (카드처럼 연출도 유저 콘텐츠)
- 지금 당장 만들지는 않지만, 나중에 막히지 않도록 아래 방향을 전제로 한다 (제안):
  - 공유할 수 있으려면 연출이 **코드가 아니라 데이터**여야 한다. 유저 연출 = 기본 동작 단계(이동, 회전, 크기, 흔들기, 페이드, 이미지·파티클 표시, 사운드, 대기)를 **순차/동시**로 조합한 JSON "연출 프리셋".
  - 연출 프리셋은 이미지·사운드처럼 **내용 해시로 참조**하고, 대전 시작 시 상대에게 없는 프리셋만 전송한다 (§9와 같은 구조). 카드의 `presentation` 값이 기본 연출 ID 또는 프리셋 해시를 가리킨다.
  - 공유 경로: 1차는 **파일 내보내기/가져오기**, 서버가 생기면 갤러리(업로드)로 확장.
- 미정 (Q12):
  - 연출 1개 최대 길이 (상대 화면에서도 재생되므로 대전 템포 보호 필요. 예: 3초)
  - "상대의 커스텀 연출 끄기 / 기본 연출로 보기" 옵션 제공 여부
  - 유저 연출 제작 도구(연출 에디터)의 범위

### 7.6 피해 유형 — 확정 (2026-10-15)

| 피해 유형 | 무엇 | 걸리는 트리거 |
|---|---|---|
| **효과 피해** | 카드 효과의 "피해" 행동으로 주는 피해 | 효과 피해를 받을/줄 때, 모든 피해를 받을/줄 때 |
| **전투 피해** | 공격으로 주는 피해와 **반격 피해**(공격받은 기물이 되돌려주는 피해) 모두 | 전투 피해를 받을/줄 때, 모든 피해를 받을/줄 때 |
| **피로 피해** | 덱이 바닥났을 때 받는 규칙 피해 | **모든 피해를 받을 때에만** 걸림 (효과·전투 피해 트리거에는 걸리지 않음). 주는 쪽이 없으므로 "줄 때"에는 해당 없음 |

- 트리거는 받을 때 3종(효과 / 전투 / 모든) + 줄 때 3종(효과 / 전투 / 모든).
- 기존 카드의 "피격 시"는 **"모든 피해를 받을 때"**로 자동 이전한다 (카드 스키마 버전 올림 + 마이그레이션).
- 점수 배율(§6.1): 새 피해 트리거 6종은 우선 기존 피격 배율(×1.2)을 쓰고, `ScoreTable`에서 개별 조정한다. — 제안
- 키워드나 효과가 피해 유형에 따라 달리 동작하게 할 때(예: 나중에 추가될 보호막류)는 이 구분을 따른다.

  - 통신은 `ITransport` 인터페이스로 분리해 교체 가능하게.

### 8.1 시간 제한·연결 끊김 — 확정 (2026-10-13, 숫자는 §3.2 임시값)

- 온라인 대전에서만 적용한다(싱글 배틀은 시간 제한 없음). 시간은 방장(호스트)이 잰다.
- **턴 타이머**: 내 턴 시간(75초)이 다 되면 자동으로 턴을 끝낸다. 체인 기회(선택)는 따로 제한 시간이 있고, 넘으면 자동 선택(패스할 수 있으면 패스, 아니면 첫 번째 강제 효과를 올림).
- **연속 시간 초과 패배**: 시간 초과로 자동 처리된 것이 연속 3번이면 패배. 직접 행동하면 횟수가 0으로 돌아간다.
- **연결 끊김**: 끊긴 플레이어는 바로 지지 않는다. 그 사람이 행동할 차례마다 20초를 기다린 뒤 자동 선택(위와 같은 방식)을 한다. 끊긴 채 자동 선택이 3번(시간 초과 횟수와 **따로** 셈)이면 패배. 다시 접속하면 그대로 이어서 한다.
- **방장 끊김**: 호스트 판정 P2P라 대전 상태가 방장에게만 있어 게스트가 대신 진행할 수 없다. 게스트는 재접속을 기다리고, 60초 안에 돌아오지 않으면 대전을 끝낸다. 이때의 승패 처리는 미정(지금은 무효 종료).
- UGS(Relay·Lobby)는 사용자가 Unity 대시보드에서 프로젝트를 연결한 뒤 붙인다. 그 전까지는 메모리 안 가짜 연결(루프백)로 개발·테스트한다.

## 11. 화면·조작(UX)과 대전 편의 — 확정 (2026-10-15)

온라인 연결(M6-4) 전에 완성도를 높이는 작업. 구현은 Roadmap **M5.5**.

### 11.1 카드 표시
- **카드 설명(설정, flavor)**: 카드에 이야기·설정 문구 칸을 추가한다. 점수에 영향 없음, 자세히 보기에서만 표시. 최대 글자 수는 개발 측 제안값으로 정하고 `RuleConfig`/검사기에 둔다. → 제안값 **100자** (`RuleConfig.MaxFlavorLength`, 줄바꿈 포함, 사용자 확인 전) — 제안 (2026-10-15)
- **손패에도 효과 글씨 표시**: 손패 크기에서도 읽히게 글씨 크기 자동 축소, 키워드는 굵게.
- **효과 설명 묶기**: 트리거와 조건이 같은 효과들은 한 문장으로 묶어 설명한다. 예) "상대가 카드를 사용할 때: 무작위 적 기물 하나에게 1 피해를 주고, 내 영웅의 체력을 1 회복한다." 문구는 그대로 쓸 필요는 없고, 사용자가 이 흐름으로 이해할 수 있으면 된다. 설명문에는 "하수인"이 아니라 **"기물"**을 쓴다.
- **키워드 설명 창**: 키워드(일회성, 은신 등) 설명은 카드 안이 아니라 **카드 밖 왼쪽 위**에 작은 창으로 따로 붙인다.
  - 키워드 1개당 1줄 (`일회성: 효과 설명`), 추가될 때마다 **아래로** 쌓인다.
  - 창들의 좌우 여백(패딩)과 위치를 맞춘다.
  - 소환물을 생성하는 효과가 있으면 그 자리에 **소환물 카드를 작게** 띄우고, 클릭하면 그 소환물의 자세히 보기로 간다.
- **설명문·키워드 창은 하나의 생성기**를 쓴다. 카드 제작기 미리보기와 대전 화면이 똑같이 보여야 한다.
- **게임 용어 툴팁**: 효과 문장 속 용어("효과 피해", "체인", "소멸" 등)에 마우스를 올리면 짧은 설명.
- **보드 위 상태 아이콘**: 도발·은신 등 키워드 표시, "턴 종료 시"·"사망 시" 등 발동 예정 효과가 있는 기물에 작은 아이콘.
- **수치 변화 색**: 원래보다 오른 공격력·체력은 초록, 피해 입은 체력은 빨강. 손패 코스트가 바뀌어도 같은 규칙.

### 11.2 카드 조작
- **호버**: 손패 카드에 마우스를 올리면 카드가 손패에서 위로 튀어나와 크게 보인다.
- **드래그**: 카드를 집어 옮기는 동안 손패에 있을 때보다 크게 보여 정보가 잘 보이게 한다.
- **홀드해서 읽기**: 카드를 누르고 있으면 카드가 앞으로(카메라 쪽) 나오고, 떼면 제자리로 돌아간다.
  - 드래그와 구분: 누른 채 움직이면 드래그, 약 0.3초 가만히 누르면 읽기. — 제안(값은 조정 가능)
  - 기존 "짧은 클릭 → 크게 보기 창"을 유지할지 — 미정 (Q15)
- **가능 여부 표시**: 낼 수 있는 카드, 공격할 수 있는 기물, 고를 수 있는 대상, 체인으로 대응할 수 있는 카드를 빛(테두리)으로 표시. 색만 쓰지 않고 테두리 두께나 아이콘도 함께 써서 색약을 고려한다. 못 내는 이유(코스트 부족, 칸 가득 참) 안내.
- **대상 지정 중 화면 가림 방지**: 대상을 고르는 동안(예: 화염탄) 사용 중인 카드는 화면 옆으로 작게 치우고, 고를 수 있는 대상을 강조한다.
- **공격 결과 미리보기**: 공격 화살표를 대상에 올리면 예상 피해와 사망 여부 표시.
- **상대의 대상 지정 보여주기**: 상대(AI 포함)가 대상을 고르면 화살표를 잠깐 보여준다.
- **ESC 우선순위**: 진행 중인 동작(대상 지정, 자세히 보기 등)을 먼저 취소하고, 취소할 게 없을 때만 메뉴를 연다. 대상 지정은 우클릭으로도 취소.

### 11.3 대전 흐름
- **코인 토스**: 대전 시작 시 코인 토스 연출로 선공/후공을 정한다. 온라인에서는 방장이 결과를 조작할 수 없게 양쪽 난수를 합쳐 정한다.
- **멀리건(시작 손패 교체)**, **후공 보정 카드** — 방식 미정 (Q14). 코인 토스와 같은 묶음에서 구현.
- **코스트 보석 UI**: 하스스톤처럼 보석으로 표시. 턴 시작 시 채워지는 연출, 소모 시 연출, 카드에 마우스를 올리면 쓸 보석이 깜빡이는 미리보기, 부족하면 흔들림.
- **턴 안내**: "내 턴" 배너, 할 수 있는 행동이 없으면 턴 종료 버튼 강조, 남은 덱 장수·상대 손패 장수 표시, 묘지 목록 보기.
- **행동 기록(로그) 패널**: 무슨 일이 일어났는지 순서대로.
- **체인 표시**: 체인에 쌓인 효과를 카드 이름만이 아니라 **카드 이미지(작은 카드)**와 함께 순서대로 보여준다. 올리면 확대.
- **ESC 메뉴**: 계속하기 / 설정 / 항복 / 메인으로. **싱글 배틀에도 항복** 추가.

### 11.4 영웅 커스터마이징 — 확정(방향), 세부 미정 (Q11)
- 유저가 영웅을 만든다: **이미지(등 정보) + 목소리 + 능력(하스스톤 영웅 능력처럼)**.
- 능력은 기존 효과 블록을 재사용하고, 카드 제작기에 영웅 제작 탭을 둔다. AI도 영웅 능력을 쓰게 한다.
- 미정 (Q11): 덱마다 영웅 1명 지정 여부, 능력 형식(코스트·턴당 횟수), 영웅별 체력 차이, 영웅 능력 점수와 방 규칙 상한 적용 여부, 목소리 재생 상황 목록, 감정표현 기능 여부.

### 11.5 소리·설정·도움말
- 배경음악, 효과음(버튼·피격·보석·코인 등), 카드에 사운드가 없을 때 쓸 기본 등장/퇴장 사운드. 사운드 에셋 수급 방식 — 미정 (Q16)
- **설정 화면**: 볼륨(배경음/효과음/음성), 해상도, 전체화면/창모드, 연출 속도. ESC 메뉴와 시작 화면에서 연다.
- **규칙 도움말·키워드 사전**. 튜토리얼은 나중.
